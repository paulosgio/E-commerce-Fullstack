# 🛒 E-commerce Fullstack

Aplicação de e-commerce full-stack desenvolvida com **React + TypeScript** no frontend e **Node.js + Express + MongoDB** no backend.

O projeto foi desenvolvido com o objetivo de praticar a construção de uma aplicação completa, trabalhando desde a interface e gerenciamento de estado até a criação de uma API REST, autenticação e persistência de dados.

## 🚀 Demo

🔗 **Aplicação:** https://e-commerce-fullstack-tawny.vercel.app/

## 📌 Sobre o projeto

Este projeto consiste em uma aplicação de comércio eletrônico com frontend e backend separados.

A aplicação permite trabalhar com funcionalidades comuns de um e-commerce, utilizando uma arquitetura baseada na separação entre cliente e API.

### Principais tecnologias

**Frontend**

- React
- TypeScript
- Vite
- Tailwind CSS
- Axios
- React Hook Form
- React Router
- Zustand
- Sonner

**Backend**

- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- bcrypt
- dotenv
- CORS

## 🧠 Conceitos praticados

Durante o desenvolvimento deste projeto foram trabalhados conceitos como:

- Desenvolvimento de APIs REST
- Integração entre frontend e backend
- Autenticação baseada em JWT
- Hash de senhas
- Persistência de dados com MongoDB
- Modelagem de dados com Mongoose
- Gerenciamento de estado global
- Formulários controlados
- Proteção de rotas
- Componentização com React
- TypeScript
- Variáveis de ambiente
- Integração com APIs utilizando Axios
- Organização de aplicações full-stack
